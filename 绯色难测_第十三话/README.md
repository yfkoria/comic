本话从期末出分前夜的五十四级进步墙和课题本，推进到两局各胜一场、暂存赌注、联名一百零八杯奶茶，再以未说完的愿望、错开的寒假值班和观测日记收束。均分差0.3、两种画展评选、三人香菜订单、相邻椅子与第十九张照片均按原作处理；爻光愿望继续留白，不提前展开初雪。

主角头脸沿用已校正的校园辨识：绯英的短蓬粉发冠、外翻脸周短层、独立细长后束及紫水晶眼；爻光的分束弯刘海、外翘侧束、右鬓羽饰与自然紫青虹彩眼。日常校园服装衔接第十二话：绯英左手新黑露指薄掌手套、右手白全指手套；爻光双手裸露，玉镯只在解剖左腕。借出的粉围巾仍归爻光暂存，不添加无源归还。配角维持已建立的高中生及成年管理者身份，个人与独立全页审阅范围详见角色核对文件。

原设JPG与人物、场景参考随包提供，实际清单见逐页制作提示的`references`。路径均为包内相对路径；导出脚本动态收集PNG、JPG/JPEG、WEBP参考，校验真实格式并记录SHA-256，不转码或缩放原设图。每页提示参考不超过图像工具实际支持的五张，本话其他成稿页也可作后续页参考。生成记录中的绝对路径只作历史来源记录；阅读成稿和重新导出不依赖这些外部路径。最终页序的`source`指向当前采用来源，`history`单独保留历次版本。

PDF按原比例无损嵌入二十四张最终PNG。导出脚本完整解码图片，检查空白与像素重复页，并以原始分辨率回渲PDF，逐页核对RGB像素。检查文件记录成稿及参考图的字节数、分辨率和SHA-256；ZIP另校验CRC、文件清单、Markdown相对链接及提示参考路径。

重新导出：在装有PyMuPDF和Pillow的Python环境中执行`python export_pdf.py`。脚本仅在二十四张成稿及全部支持文件齐备、角色终表已完成并冻结时导出。ZIP使用Deflate压缩；若含PDF的完整包达到100MiB，则改为原图包，PDF单独提供。原始图片不拆分、不降分辨率。包内只含本话交付资料。

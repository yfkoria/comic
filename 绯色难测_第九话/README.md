主角沿用第七、八话校正后的辨识：绯英的短蓬发冠、外翻脸周层与紫水晶眼，爻光的分束刘海、外翘侧束与自然紫青虹彩眼。校园服装使用已确认版本，实际逐页对照及审阅者记在角色核对文件中。花火的造型依据本章小说所述成年团长、深红卷发尾与左半素白面具登记为本话适配设计，未冒称用户已提供其原设。

虚构漫画《苍天航路绒绒号》的兔、蛋、稻草人与獾均为转述中的画中画。两只成品狐面具始终分别归属主角：银线白狐、额心一点朱砂归爻光，金边红狐归绯英；绘制回叙与现场成品分开检查。

原设 JPG 与人物、场景参考随包提供，实际清单见逐页制作提示的 `references`。路径均为包内相对路径；导出脚本动态收集 PNG、JPG/JPEG、WEBP 参考，校验真实格式并记录 SHA-256，不转码或缩放原设图。每页提示参考不超过图像工具实际支持的五张，本话其他成稿页也可作后续页参考。生成记录中的绝对路径只作历史来源记录；阅读成稿和重新导出不依赖这些外部路径。最终页序的 `source` 指向当前采用来源，`history` 单独保留历次版本。

PDF 按原比例无损嵌入二十张最终 PNG。导出脚本完整解码图片，检查空白与像素重复页，并以原始分辨率回渲 PDF，逐页核对 RGB 像素。检查文件记录成稿及参考图的字节数、分辨率和 SHA-256；ZIP 另校验 CRC、文件清单、Markdown 相对链接及提示参考路径。

重新导出：在装有 PyMuPDF 和 Pillow 的 Python 环境中执行 `python export_pdf.py`。脚本仅在二十张成稿及全部支持文件齐备、角色终表已完成并冻结时导出。ZIP 使用 Deflate 压缩；若含 PDF 的完整包超过 100 MiB，则改为原图包，PDF 单独提供。原始图片不拆分、不降分辨率。包内只含本话交付资料。

# 绯色难测 · 第十话 · 救场

主角沿用已校正的辨识：绯英的短蓬粉发冠、外翻脸周短层与紫水晶眼，爻光的分束弯刘海、外翘侧束、右鬓羽饰与自然紫青虹彩眼。上身及独立半裙沿已确认的校园服装；本话足部统一为踝上止口的同色深色无足裤袜，使失鞋后赤足与原作相符。绯英伤在左掌，左黑露指手套被剪开后改为左手白纱布包扎，右白全指手套保持；爻光仍为裸双手、左腕玉镯、右腕空净。实际逐页对照与审阅范围记在角色核对文件中。

白露沿第三话高中生保健委员形象，符玄沿第二话成年教务主任形象，银狼沿既有转校生形象。刃的成年校医白大褂、深色束发与手部近景为本章小说约束下的校园适配设计。花火沿第九话成年团长与左半素白面具的适配形象。新增适配均在角色核对中登记。

原设JPG与人物、场景参考随包提供，实际清单见逐页制作提示的`references`。路径均为包内相对路径；导出脚本动态收集PNG、JPG/JPEG、WEBP参考，校验真实格式并记录SHA-256，不转码或缩放原设图。每页提示参考不超过图像工具实际支持的五张，本话其他成稿页也可作后续页参考。生成记录中的绝对路径只作历史来源记录；阅读成稿和重新导出不依赖这些外部路径。最终页序的`source`指向当前采用来源，`history`单独保留历次版本。

PDF按原比例无损嵌入二十二张最终PNG。导出脚本完整解码图片，检查空白与像素重复页，并以原始分辨率回渲PDF，逐页核对RGB像素。检查文件记录成稿及参考图的字节数、分辨率和SHA-256；ZIP另校验CRC、文件清单、Markdown相对链接及提示参考路径。

重新导出：在装有PyMuPDF和Pillow的Python环境中执行`python export_pdf.py`。脚本仅在二十二张成稿及全部支持文件齐备、角色终表已完成并冻结时导出。ZIP使用Deflate压缩；若含PDF的完整包超过100MiB，则改为原图包，PDF单独提供。原始图片不拆分、不降分辨率。包内只含本话交付资料。

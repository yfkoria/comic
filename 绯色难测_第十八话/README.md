四月末督导周，从市局文件、迎检清单与信息中心走到绘世楼午间笔会。旧名“尺英”被华叫破，邀请和判词留在门外的脚步声中；下午照常上课，放学后重看学生作品，深夜独自面对玻璃倒影。止于第十八章关灯，不提前下一章的雷雨与意外。

角色以用户原设和已核校园日装为身份依据。绯英白天保持紫色美瞳，短蓬粉发主冠、外翻短脸层、独立细长后束及红结樱夹清楚，右白全指与左黑露指薄手套不互换；夜间摘瞳前先脱下两只手套，露出的手不新增伤口，摘瞳后按原作呈现琥珀金眼睛。爻光的右腕已在前话三天后拆去绷带，本话裸腕；玉镯始终在解剖左腕。华按小说的成年督学、利落短发和深色大衣设计，不冒充用户提供过的参考设定。

五十四格墙报与“我们喜欢周三下午”、碎裂又愈合的行星、木尺、第五十三格、301灯下的倒影与路灯按本话分镜逐页核对。花火原话为半年前的回忆，不让剧团团长现时到校；金瞳揭示属于绯英独处场景，不新增爻光在场或知情。

原设JPG与人物、场景参考随包提供，实际清单见逐页制作提示的`references`。路径均为包内相对路径；导出脚本动态收集PNG、JPG/JPEG、WEBP参考，校验真实格式并记录SHA-256，不转码或缩放原设图。每页提示参考不超过图像工具实际支持的五张，本话其他成稿页也可作后续页参考。生成记录中的绝对路径只作历史来源记录；阅读成稿和重新导出不依赖这些外部路径。

PDF按原比例无损封装三十二张最终PNG；常规RGB原图直接使用原有压缩数据，原PNG文件不变。导出脚本完整解码图片，检查空白与像素重复页，并以原始分辨率回渲PDF，逐页核对RGB像素。检查文件记录成稿及参考图的字节数、分辨率和SHA-256；ZIP另校验CRC、文件清单、Markdown相对链接及提示参考路径。

重新导出：在装有PyMuPDF和Pillow的Python环境中执行`python export_pdf.py`。脚本仅在三十二张成稿及全部支持文件齐备、角色终表已完成并冻结时导出。ZIP使用Deflate压缩；若含PDF的完整包达到100MiB，则改为原图包，PDF单独提供。原始图片不拆分、不降分辨率。包内只含本话交付资料。

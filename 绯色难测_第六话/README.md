# 绯色难测 · 第六话 · 朱批

十六页、72格全彩漫画，1024×1536。改编卷一第六章，从幻月祭共同执祭的任命、红字修改与现场筹备，推进到食堂与十一月审批。两位成年教师的关系通过数周工作往来慢慢改变。

角色与画风参考随包提供，参考清单见逐页制作提示的 `references`。这些路径均使用包内相对路径，导出脚本会把实际使用的参考 PNG 自动加入交付包；本话其他已完成页面也可用作后续页的参考。生成记录中的旧绝对路径仅供历史溯源，阅读成稿与重新导出不依赖这些路径。最终页序的 `source` 记录当前采用的来源，`history` 独立保存历史版本。

PDF 按原比例无损嵌入十六张成稿 PNG。导出脚本完整解码图片，检查空白和像素重复页，并将 PDF 以原始分辨率还原后逐页核对 RGB 像素。检查文件记录每页字节数、分辨率与 SHA-256；ZIP 另行校验 CRC、文件清单、Markdown 相对链接和绘图提示中的参考路径。

重新导出：在装有 PyMuPDF 和 Pillow 的 Python 环境中执行 `python export_pdf.py`。脚本仅在十六张成稿和全部支持文件齐备时导出。ZIP 使用 Deflate 压缩；若包含 PDF 的 ZIP 超过 100 MiB，将自动改为不含 PDF 的原图包，PDF 仍单独保留。导出不会生成或替换漫画图片，也不会拆分或降低原图分辨率。包内不含原作小说、其他话漫画或旧交付包。

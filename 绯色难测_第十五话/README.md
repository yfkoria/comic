两副红联、冰壳上的夜路、无声的新年祝福与未结的时间账，收束这一卷的日常往来。账页日期和条目保留原文，雪球条目作为账本中的记述；年度复诊通知保留为预约提醒。末尾是隔墙跑调的新年歌和保持敞开的内部通气窗。

主角沿用原设校正的头脸发眼及第十四话冬装。绯英的粉围巾已归还，本话户外可由她佩戴；爻光继续借用蓝灰备用颈巾，与原navy肩布独立。绯英右白全指、左新黑露指薄掌手套，爻光裸双手、玉镯仅在解剖左腕。室内外衣物阶段与个人实际审阅范围详见逐页分镜和角色核对文件。

302的红联为五字上、下联与单字横批“赢”，右下朱砂狐狸爪印；301的回联为四字上、下联与“平安”，右下铜钱大小的二维圆墨点。明信片、拍下的同一副对联壁纸、账本及手机朝下扣在书上的位置均逐页检查。

原设JPG与人物、场景参考随包提供，实际清单见逐页制作提示的`references`。路径均为包内相对路径；导出脚本动态收集PNG、JPG/JPEG、WEBP参考，校验真实格式并记录SHA-256，不转码或缩放原设图。每页提示参考不超过图像工具实际支持的五张，本话其他成稿页也可作后续页参考。生成记录中的绝对路径只作历史来源记录；阅读成稿和重新导出不依赖这些外部路径。

PDF按原比例无损封装二十八张最终PNG；常规RGB原图直接使用原有压缩数据，原PNG文件不变。导出脚本完整解码图片，检查空白与像素重复页，并以原始分辨率回渲PDF，逐页核对RGB像素。检查文件记录成稿及参考图的字节数、分辨率和SHA-256；ZIP另校验CRC、文件清单、Markdown相对链接及提示参考路径。

重新导出：在装有PyMuPDF和Pillow的Python环境中执行`python export_pdf.py`。脚本仅在二十八张成稿及全部支持文件齐备、角色终表已完成并冻结时导出。ZIP使用Deflate压缩；若含PDF的完整包达到100MiB，则改为原图包，PDF单独提供。原始图片不拆分、不降分辨率。包内只含本话交付资料。

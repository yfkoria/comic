本话沿用第七话校正后的角色辨识：绯英短蓬发冠、外翻脸周层与紫水晶眼，爻光弯碎刘海、外翘侧束与自然紫青虹彩眼。校园服装使用已确认版本；本章原作中的淡青眼圈和困倦神态照常保留，实际逐页对照与审阅人员记在角色核对文件中。停云以递函手或侧背影取景，不新增未经参考确认的完整外貌。

原设 JPG 与校园场景参考随包提供，清单见逐页制作提示的 `references`。这些路径均为包内相对路径；导出脚本自动收集 PNG、JPG/JPEG、WEBP 参考，校验真实格式并记录 SHA-256，不转码或缩放原设图。本话其他成稿页也可作后续页参考。生成记录中的旧绝对路径只记录历史来源；阅读成稿和重新导出不依赖这些外部路径。最终页序的 `source` 指向当前采用来源，`history` 单独保留历次版本。

PDF 按原比例无损嵌入十六张最终 PNG。导出脚本完整解码图片，检查空白与像素重复页，并以原始分辨率回渲 PDF，逐页核对 RGB 像素。检查文件记录成稿及参考图的字节数、分辨率和 SHA-256；ZIP 另校验 CRC、文件清单、Markdown 相对链接及提示参考路径。

重新导出：在装有 PyMuPDF 和 Pillow 的 Python 环境中执行 `python export_pdf.py`。脚本仅在十六张成稿及全部支持文件齐备时导出。ZIP 使用 Deflate 压缩；若含 PDF 的完整包超过 100 MiB，则改为原图包，PDF 单独提供。原始图片不拆分、不降分辨率。包内只含本话交付资料。

# 绯色难测

校园背景的成年双女主漫画改编项目。现有五话，共64页：第一话十页，第二话十二页，第三至第五话各十四页。人物关系保持慢热。

## 第五话：不可测变量

十四页、64格，改编《乱卦》：青雀的铜钱事件、概率作业、卦簿核对与新的课题本。全部画稿已逐页复核，提供连续阅读 PDF、完整包与原图。
